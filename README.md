# ASBL Projects Showcase

A modern, highly interactive web application built to list ASBL's apartment projects. Designed with a premium, smooth UX as a submission for the ASBL frontend developer assignment.

## 🚀 Tech Stack
- **Next.js**
- **Tailwind CSS** 
- **Framer Motion**

## 💻 Running Locally

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm run dev
```

3. Open [http://localhost:3000](http://localhost:3000) with your browser.
